# Security policy

## Reporting a problem

Report security problems **privately**, never in a public issue or on Discord:
use GitHub's private reporting for this repository
([Report a vulnerability](https://github.com/Kyle-Hosman/az-mods-examples/security/advisories/new),
under the Security tab).

Include what is affected (version, firmware, platform), how to reproduce it, and what
an attacker could do with it. The maintainer aims to answer within a week, and asks for a
reasonable time to ship a fix before details are published. Reporters are credited in the
release notes unless they ask not to be.

## Scope

| Problem in | Report to |
|---|---|
| AZ-MODS itself | [xdj-az-mods](https://github.com/Kyle-Hosman/xdj-az-mods/security/advisories/new) |
| the SDK, its harness or `azmod-pack` | [az-mods-sdk](https://github.com/Kyle-Hosman/az-mods-sdk/security/advisories/new) |
| the example mods in this repository and their release workflows | this repository |

## Supported versions

The latest release of each example mod.
